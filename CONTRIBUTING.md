# Component package quality standard

This repository provides reusable ebook-cover UI components.

## Acceptance checklist

- Preserve the documented `book` input shape.
- Keep keyboard interaction and ARIA labels intact.
- Verify export and print behavior in a real browser before release.
- Keep generated assets and customer content out of commits.
- Update `INSTALL.md` and the integration patch when public component behavior changes.

Run `npm run validate` before submitting changes.
